# 소스 복원 기록

2026-10-20 사용자 제공 학교 ZIP과 웹프로젝트 쿼리문에서 텍스트 소스를 복원했습니다.

- 원본 Java·JSP·CSS·JavaScript·MANIFEST를 webproject/ 아래에 배치했습니다.
- 컴파일된 class와 배포 JAR는 제외했습니다. 의존성은 추가한 Maven 설정에 명시했습니다.
- JDBC 접속 정보는 DB_URL·DB_USER·DB_PASSWORD로 변경했습니다.
- 고정 관리자 비밀번호를 제거하고 선택적인 환경변수 초기화로 변경했습니다.
- 스키마는 DDL만 포함하고 실제 회원·메시지 데이터는 추가하지 않았습니다.
- ZIP의 이미지 전체와 원본에 없는 SVG는 포함하지 않았습니다.
- 공개 저장소에 남아 있던 초기 화면 자료는 덮어쓰거나 삭제하지 않았습니다.

소스 구조·파일 수와 접속값 제거를 대조했습니다. 2026-10-20 기존 JDK 17과 Maven Central의 javax.servlet-api 4.0.1로 Java 소스 16개를 컴파일해 통과했습니다. XML 형식과 SQL의 테이블 정의도 확인했습니다. Maven WAR 패키징·JSP 컴파일·실제 Tomcat·MySQL 구동 및 화면 시험은 수행하지 않았습니다.
