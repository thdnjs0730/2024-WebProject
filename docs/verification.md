# 실행 점검 기록

검증일: 2026-10-20 (한국 시간).

## 확인한 환경과 결과

| 항목 | 결과 |
| --- | --- |
| JDK 17 / Maven 3.9.9 | Java 컴파일 및 WAR 패키징 성공 |
| Tomcat 9.0.123 + H2 MySQL 모드 | HTTP 통합 테스트 5개 통과 |
| Tomcat 9.0.123 + 실제 MySQL 8.4.0 | HTTP 통합 테스트 5개 통과 |
| `/pet-adoption` 컨텍스트 배포 | 폼 전송·화면 이동·사진 조회 확인 |
| 루트 컨텍스트 배포 | 실제 MySQL로 HTTP 통합 테스트 5개 통과 |
| 독립 Tomcat WAR 배포 | 서버 기동 및 HTTP 응답 확인 |
| Docker Compose | 구성 추가. 이 PC에는 Docker가 없어 컨테이너 실행 자체는 미검증 |
| 브라우저 육안 확인 | 자동화 도구가 현재 URL을 판별하지 못해 중단. 완료로 간주하지 않음 |

통합 테스트는 실제 Tomcat을 시작해 HTTP 요청과 별도 사용자 세션으로 검사합니다. JSP는 요청 과정에서 실제 컴파일·렌더링됩니다. 테스트 개수는 5개지만 각 테스트가 여러 요청과 상태 검증을 포함합니다.

## 점검 흐름

1. 홈·소개·로그인·입양 목록·최신 공고·정적 자료 응답, 미로그인 접근 제한, 잘못된 공고 번호 처리.
2. 회원가입의 입력값·중복 ID, 로그인 성공/실패, BCrypt 저장, 일반 회원의 관리자 접근 차단.
3. 사진 첨부 공고 등록·상세·검색, HTML 이스케이프, 사진 응답, 작성자가 아닌 회원의 수정/삭제 차단, 사진을 교체하지 않는 수정.
4. 존재하지 않는 수신자 처리, 쪽지 전송과 받은/보낸 목록, 회원정보 수정, 비밀번호 유지/변경, 로그아웃과 재로그인.
5. 관리자 검색, 공고·사진 삭제, 관리자 계정 삭제 방지, 일반 회원 삭제와 관련 쪽지 정리.

## 수정한 주요 원인

- Eclipse 로컬 라이브러리 의존 → Maven 의존성 및 WAR 빌드.
- 고정 DB 접속값·관리자 비밀번호 → 환경변수와 선택적 관리자 생성.
- 평문 회원 비밀번호·8자 DB 컬럼 → BCrypt와 해시 길이에 맞는 새 스키마.
- 루트 기준 이동 경로 → 애플리케이션 컨텍스트 경로 반영.
- 직접 URL 접근으로 우회되는 권한 → 전체 요청 필터 및 공고 작성자 검사.
- 서버 웹 루트의 임의 파일 업로드 → 외부 저장소, 크기·이미지 형식 검사와 이미지 재인코딩.
- 사진 없는 수정 실패 → 기존 사진 유지.
- 공유된 정적 회원정보 객체 → 요청마다 새 DTO 생성.
- 받은/보낸 쪽지 조회 혼용 → 발신 쪽지 조회 분리.
- 누락된 SVG·깨진 링크·중복 슬라이더 이벤트·소개 화면의 null 요소 접근 → 해당 참조 제거 또는 수정.
- 저장소 루트와 `webproject`의 중복 소스 → 루트의 단일 Maven 프로젝트와 역할별 이름.

## 적용 범위

새 빈 DB 기준입니다. 원본 DB 데이터 마이그레이션은 하지 않습니다. 브라우저별 시각적·모바일 레이아웃과 부하 테스트는 수행하지 않았습니다. 커뮤니티와 후원은 학교 원본의 화면 예시이며 게시판·결제 기능이 아닙니다.
